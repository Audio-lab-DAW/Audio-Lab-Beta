# Shortcut icon: Ocean Yellow "W7" (zoomed + tilted)

The app's shortcut icon (Mac app icon in Dock/Finder/Launchpad, Windows exe/taskbar/Start menu/desktop shortcut) uses a zoomed crop of the Ocean Yellow logo: 1.5× zoom into the top right, moved up 40 px, tilted 6° left, electron anchored at the top right, rings cut cleanly at the left and bottom.

Size plan inside icon.icns / icon.ico:
- 16 to 20 px: the normal logo (XS tier), because a zoomed crop cannot read that small.
- 24 to 512 px: W7 (drawn per tier: L at 128+, M at 48–64, S at 24–32, with thicker lines at small sizes).
- 1024 px: the normal logo (large size stays as before).

Files: icon.icns -> desktop/build/icon.icns; icon.ico -> desktop/build/icon.ico; dock-icon.png -> desktop/dock-icon.png; shortcut-L/M/S.svg/png = sources.
Unchanged: the .audiolab document icon (doc.icns/doc.ico), the web favicons, the in-app logos, and the Settings picker ("Ocean Yellow" stays the normal logo).
