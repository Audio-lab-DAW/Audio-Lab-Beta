
## 28 November 2026, v{V}: task OV6a, tooltips as T3 callouts with a leader (lane F, overlays)

Step OV6 of `docs/design-round-5-overlays.md` section 5, built as the user's pick **T3** (callout with a leader) instead of T1, part a: the callout itself. Edit script `tools/design-lab/ov/ov6.py` with `ov6_block.js` and `ov6_css.txt` (JS before `askChoice`, CSS before `.dacv`, and six small asserted changes in lane F's own tooltip code: `tipShow`, `tipHide`, its pointerover, pointerout and pointerdown listeners, and the clip-name follower's `stop`); test `tools/ui-tests/taskOV6a.py` (36 checks). Built and tested on v0.314 during the release gate's freeze of 16:41 UTC; released by `tools/design-lab/ov/ov6_release.py` once the freeze was lifted, the edit script re-run on the fresh file.

### What changed
- **The tooltip is a callout** (the pick page's T3 card): it hangs from the control by an amber hairline with a dot (the LOOK amber, `--ov-amb`). On the card: the name in small mono capitals with the key on the right (from the shortcut list, so a key the user changed shows as changed; for example Cycle ⇧L, Play Space, Undo ⌘Z), the value now as a read-out with its unit in amber (ON/OFF of a switch or pressed button, a select's choice, a slider's value), the sentence, then DEFAULT and SCOPE for Settings rows (lane B's `ST_HOOKS.helpFor`, the S4 table), and the small picture when there is one.
- The name comes from the text that was there: a short first sentence ("Play / stop (Space)"), a short head before a colon ("Time Machine: every saved version …"), or the control's own label (aria-label, a menu row's label). No word of any tooltip is lost (checked on all 424 tooltips of the main window).
- **Times** from LOOK (`ovMs`): 500 ms before the first, then **at once for 300 ms** after one closed (moving along the transport reads every button without waiting); 80 ms fade, none with reduced motion, Motion "Signal only" or Light mode.
- **It stays while the pointer is on it or on its way to it** (the gap under the leader counts), so it can be read; leaving it hides it. **Esc hides it** (the key still reaches the rest of the app) and it does not come back until the pointer moves to another control.
- **Keyboard**: Tab or the arrow keys moving focus show the callout of the focused control after the same delay, linked by `aria-describedby` (removed again when it closes); focus set by the code (after a menu or the palette closes) shows nothing.
- **Menu rows** put the card beside the menu, the leader running sideways from the menu's edge, so the rows below stay visible.
- Settings rows that had no tooltip of their own read their line from the settings table (kept aside in the code, nothing written into lane B's rows).
- Same switch as before (Settings, tooltips off), same texts (`TIPS`, `title`, `data-tip`), `tipShow` and `tipHide` keep their names for every caller (the map's box, clip names on the canvas). Drawn solid (as the old card), no backdrop-filter; the glass engine's layers are unchanged.
