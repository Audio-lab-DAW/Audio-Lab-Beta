Menus, dialogs and notifications

Everything that floats over the work: right-click menus and the main menu, dropdowns, dialogs and sheets, tooltips and the help line, toasts, drag and drop, the command palette and the shortcut overlay. Each family starts with Today (a screenshot of v0.228 and a live copy), then numbered options. All of them open for real, work with the keyboard and show how fast they open. ★ marks the recommendation.

Try: each card's buttons, or right-click the mock track header and Mute button. Keyboard: Tab to a trigger, Enter or Shift+F10 opens, ↑ ↓ Home End move, letters jump, → opens a submenu, Esc closes and gives focus back. Pick: one number per family, then copy the line at the bottom.

R · Right-click menus, the main menu and dropdowns

one pick

Each card has three things to open: the track header menu (right-click it), the Mute button menu (right-click M: here the extensions rule K12a shows, entries that name the control in a marked Advanced group), the AudioLab menu (the logo, click), and a dropdown (Quantize).

D · Dialogs and sheets

one pick

The three dialogs the app shows most: closing a project with unsaved changes (askChoice), naming something (askText), and a working dialog with a long job (Split into stems; Export, Bounce and Audio to MIDI follow the same pattern). Enter runs the default button, Esc cancels, Tab stays inside the dialog.

T · Tooltips and the help line

one pick

Hover or Tab over the toolbar. The help line is D4c from Settings round 1 (a line at the foot of the window with the default and the scope), here used for the whole window. Every tooltip can be dismissed with Esc, stays while the pointer is on it, and shows on keyboard focus too (WCAG 1.4.13).

N · Toasts, notifications and progress

one pick

Five kinds of message: a finished action with Undo, an error, the update notice, the Light-mode notice, and a long job with progress. Progress uses the orbit loader of task MD1 (M2) as it is specified, not a new design.

X · Drag and drop

one pick

Drag the file chip from the tray onto the lanes (or below the last lane for a new track). With the keyboard: focus the chip, Space picks it up, arrows move, Space drops, Esc cancels. You can also drop a real audio file from your computer onto the lanes.

K · Command palette and keyboard shortcuts

one pick

The commands are AudioLab's real list (SCA, 57 actions with their default keys). Click into a card's window first, then use the keys shown; the buttons do the same. Note: ⌘K is the Assistant today, and ⌘/ opens Keyboard shortcuts.

The rules the options follow

  • Context menus: few items, at most about three groups, one level of submenus, no shortcuts needed in context menus, every command also in a main menu (Apple, Context menus).
  • Menu labels: "…" when more input follows; icons for every item in a group or none (Apple, Menus); macOS 26 put icons on every item and was widely criticised (MacRumors).
  • Keyboard: focus the first item, arrows, Home/End, type-ahead, Esc gives focus back to the trigger (WAI-ARIA menu pattern); modal dialogs keep Tab inside and focus the least destructive button for things that cannot be undone (APG dialog).
  • Alerts: up to three buttons, specific verbs, Cancel on the leading side, default on the trailing side (Apple, Alerts; Windows, Dialogs).
  • Notifications: one place, combine messages, a way to keep one open; low-priority progress in the status bar (VS Code; Primer).
  • Help on hover: Ableton's Info View shows "the name and function of whatever element" is under the pointer (Live 12 manual).
  • Command palettes: ⌘K in Figma, Linear and Raycast, keys on the right, fuzzy search (Raycast action panel; Linear).
  • Labels on instruments: all capitals is fine for labels, mixed case for messages and menus (FAA flight-deck guidance).
