Readability of the theme

Every rule, worst pair shown

Each rule checks its token against every surface it can sit on, including glass over the brightest and darkest clip. The worst pair is shown; the count says how many pairs were checked. Text needs both the WCAG ratio and the APCA level; controls and graphics need 3 : 1 (WCAG 1.4.11).

Track colours under colour-vision deficiency

Smallest CIEDE2000 difference between any two of the eight track colours, simulated with Machado 2009. 10 and up is colour-blind friendly (cols4all), under 6 fails.

Meaning colours kept apart

Selection, record, clip and the accent must never be mistaken for each other (CIEDE2000).

Glass

The floor is the lowest panel opacity at which main text, labels and quiet text still pass over the brightest clip behind the glass. The glass engine keeps its look (refraction, edge); only its tint never goes below the floor.

What the readability fit changed

Colours as drawn from the icon, then fitted: only lightness moves, hue stays. Track colours were tuned within a small range for colour-vision safety.

Clip titles

The title ink on each clip is picked per clip (theme ink, near black or white), whichever reads best.

Today

How themes work in AudioLab now

Three layers that grew separately

  • CSS custom properties at the top of the style block: --bg --pn --pn2 --ln --ink --mut --acc --blue, --gtr (strip colour), --glass, and task LK's --sel --unit --meas --lim-warn --lim-over --lk-hair.
  • The LOOK object (task LK) that canvas drawers read: grid levels, ink, quiet grey, units amber, selection yellow, limits, density.
  • TH, written by applyTheme() from three sliders (hue 215, tint 25 %, background 40 %): lanes, ruler, grid, map.

"Studio themes" already exist

  • THEMES holds 8 looks of other programs (AudioLab, Live, FL, Cubase, Logic, Bitwig, Pro Tools, Reaper): panel colours, accent, arrangement, clip shape, fader design and meter colours, painted by thPaint().
  • Light arrangements (Pro Tools style) already force glass to 90 % (thGlass()), the same idea as the glass floor here.
  • "Light mode" in AudioLab today is the performance mode for slow computers (UI.lite), not a colour theme.

What would have to change

  • index.html has about 4,300 hex colours and 2,400 rgb() literals; only about 1,200 places read a variable. The chrome (panels, text, lines, menus, strips) has to read semantic tokens.
  • Device displays keep their dark wells in every theme. That keeps most of the literal colours (science drawings, meters, scopes) valid and measured against one known dark ground.
  • THEMES becomes a list of theme files in one format; the 8 studio looks become the group "Other programs" in the same list.
  • Lane P's Night mode and OLED care stay on top of any theme: Night is a filter, OLED care dims tokens.
Design

The theme system

Three tiers

  • Primitives: each theme's raw colours (the icon's paper, ink, nucleus, electron).
  • Semantic tokens, the same names in every theme: surfaces, lines, four text levels, accent, selection, units, record, over, warn, ok, playhead, meter stops, focus ring, glass and its floor, clip opacity, eight track colours.
  • Component tokens only where needed, as aliases (strip.name = ink).
  • A theme changes values, never names or meanings (IBM Carbon's rule). Record stays red, selection stays the selection, in every theme.

One file per theme, live switch

  • Each theme is a JSON file in the W3C Design Tokens format (2025.10: $value, $type, aliases), bundled into index.html at release.
  • Switching writes the tokens once: CSS variables on :root, a fresh LOOK, TH, then one redraw. No reload, nothing per frame; drawers read the same objects as today.
  • Your Hue, Tint and Background sliders stay as "Adjust" on top of any theme, clamped so the rules keep passing.
  • Follows the system light or dark appearance if wanted (a light and a dark theme chosen as a pair, like B and B2).

A contrast gate

  • check.py --gate measures every theme file and fails the release when a rule fails, like GitHub Primer's contrast workflow.
  • 94 pairs per theme: WCAG 2.2 ratio, APCA 0.1.9 level, CIEDE2000 under protan, deutan and tritan.
  • Today's theme A is the baseline: its 5 known misses are listed and only new misses fail the gate.
